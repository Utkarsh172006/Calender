# 📅 CalendarReminder - Java Console Application

## 📝 Description

**CalendarReminder** is a basic Java console-based application that allows users to set, view, and manage reminders for specific calendar dates. It's ideal for beginners learning Java fundamentals like arrays, user input handling, and switch-case logic.

---

## 🔧 Features

- ✅ Add a reminder for a specific day, month, and year
- ✅ View all saved reminders
- ✅ Exit the application gracefully
- 🛑 Fixed-size storage for up to 100 reminders (uses arrays)

---

## 🖥️ How It Works

### Menu Options:
1. **Add a Reminder**  
   Prompts user to enter:
   - Day (1–31)
   - Month (1–12)
   - Year (e.g., 2025)
   - Reminder message (e.g., "Doctor appointment at 5 PM")

2. **View Reminders**  
   Displays a list of all reminders with their associated dates.

3. **Exit**  
   Terminates the application.
